# ナガシマス

地形を組み替え、降雨を受け止め、必要な場所へ安全に水を流すブラウザ向け治水パズルゲームです。

計画書の承認を終え、M1「画面を持たない水流モデル」とM2「施工候補とステージ進行」をマージしました。M3では、M2のルールをそのまま使うCanvas盤面、仮置きプレビュー、タッチ入力の基礎を追加しています。

## 現在の範囲

- 8×8盤面、整数の地形高さと水量
- 雨、水中施工、同時差分方式の4方向水流
- 安全排水、危険流出、排水口、保護対象の浸水判定
- 固定シード乱数、版付き操作記録、同一操作の再生
- 2候補の持ち越し、上昇・下降パーツ、回転、施工見送り
- 固定雨予報、原子的な手番進行、タイムアウト、完全Undo
- 3軸評価、厳格なステージデータ検証、高レベル再生記録
- 描画なしで完走できるステージ1～3と支配戦略検査
- ステージ1～3の手数と雨間隔を短くした、見送り連続を抑えるプロトタイプ調整
- 水量保存、計算順非依存、桁あふれ防止の自動検査
- アイソメトリック座標、全セルのヒットテスト、Pointer Eventsの単一入力管理
- 仮置きと施工確定を分離したCanvas表示の基礎
- 次の2つの雨予報を盤面へ重ねる表示、選択セルの危険度と理由表示
- 施工セル・この手の雨・次の水流を文章でも確認できるプレビュー表示
- 確定後の施工・雨・水流・評価を短く再生する表示と、再生中の入力ロック
- クリア／失敗の結果、スコア、失敗理由、即時再挑戦の表示
- 結果画面の最初の破綻、主原因の一文、次に改善する1点の表示
- ステージ1・2のクリア記録に連動したステージ2・3の解放表示
- タイトル画面、3ステップの遊び方、ステージ1～3の選択
- 初回表示と再表示に対応した折りたたみ式の遊び方
- 視差効果を減らす設定に対応した固定表示の再生演出
- ステージ3の標準／長め／無制限の思考時間、一時停止、ページ離脱時の自動停止
- ステージ2クリア後に選べる標準／高速の水流再生速度
- 設定、チュートリアル既読、最後に選んだステージ、クリア最高記録のlocalStorage保存（v1から自動移行）
- 受理済み操作列と状態ハッシュによる途中保存・再読込後の続きから再開
- 確定後の施工・雨・水流を短い脈動で追える基本演出

現在はM3の画面基礎に加え、M4のタイトルから結果までの縦切り、ステージ3の思考時間、一時停止・復帰、設定とクリア記録の保存、確定後の基本演出、水流再生速度の選択、結果画面の改善フィードバック、ステージ解放表示、途中保存・再開を実装しています。端末上の受入確認、完成版の操作調整、ステージ4～6、GitHub Pages公開は後続工程で扱います。Pagesの設定と公開は、完成後の明示承認まで行いません。

## 開発用コマンド

Node.js 22.12以上を使用します。

```bash
npm ci
npm run check
```

`npm run check`は型検査、単体テスト、ドメイン用ビルド、画面用ビルドの検査を順に実行します。画面は`npm run build:app`でも個別にビルドできます。
