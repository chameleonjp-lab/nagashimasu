# ナガシマス

地形を組み替え、降雨を受け止め、必要な場所へ安全に水を流すブラウザ向け治水パズルゲームです。

計画書の承認を終え、M1「画面を持たない水流モデル」の実装と自動検査を完了しました。現在の成果物はゲーム画面ではなく、後続の盤面表示とステージ進行が共通して使うルール層です。

## 現在の範囲

- 8×8盤面、整数の地形高さと水量
- 雨、水中施工、同時差分方式の4方向水流
- 安全排水、危険流出、排水口、保護対象の浸水判定
- 固定シード乱数、版付き操作記録、同一操作の再生
- 水量保存、計算順非依存、桁あふれ防止の自動検査

施工候補、ステージ進行、Canvas表示、タッチ操作、GitHub Pages公開は後続工程で扱います。

## 開発用コマンド

Node.js 22.12以上を使用します。

```bash
npm ci
npm run check
```

`npm run check`は型検査、単体テスト、Viteによる本番向けライブラリビルドを順に実行します。

詳しい仕様と工程は[企画・技術・実装計画書](docs/PROJECT_PLAN.md)と[M1水流モデル契約](docs/adr/0001-deterministic-water-model.md)に記録しています。
