# PR1：クリア結果を演出より先に確定する

2026-09-08。Astra highの監査・改善計画のF03に対応する。基点はmain `8d129c8f7fb377ac78ccbe7628e393e51eae85f4`。

## 解消する問題

修正前は、最終手の受理後に途中保存を削除し、クリア進捗は演出完了時に保存していた。この間に読み直しや強制メニューで演出を中断すると、クリア記録も再開用の保存も残らない。

クリア進捗の確定は、受理された最終結果を使い、演出開始前に行う。進捗を保存できた後に途中保存を片付ける。演出完了通知は、保存の条件にしない。

## 完成条件

- 最終手の受理直後、雨中、水流中、演出完了後のどの時点で中断しても、保存成功済みのクリア記録と解放が残る。
- 保存先が書き込みを拒否したり例外を返した場合は、保存できたと表示せず、現在の結果を保持して再保存できる。
- 強制メニュー、再挑戦、ステージ変更、Undo、重複・古い演出通知で、別のセッションの途中保存を消したり、記録を取り違えたりしない。
- 既存の最高記録を下げない。保存形式・キー・ステージ版・水流・勝敗・スコア式・Undo回数は変えない。

## iPhoneでの確認手順

PRに記載した確認用URLを、iPhone 17 ProのSafariで開く。対象のソース版はPR本文と確認用ページに記録する。確認用ページの保存領域は公開版と別であり、公開版のクリア履歴は引き継がない。

この手順は保存を確かめるために解法を示している。初見プレイテストには使わない。

1. 名前を入れ、ステージ1「はじめの池」を開始する。
2. 候補Aの「2マス上げ」を選び、「パーツを回す」を1回押す。A3を基準にA3・A4へ仮置きし、施工を確定する。座標が選びにくければ「盤面の見方・座標」内の座標選択を使う。
3. 2手目は「見送る」を押し、演出が終わるまで待つ。
4. 3手目も「見送る」を押し、最後の雨・水流の演出中にSafariで再読み込みする。
5. ステージ1がクリア済み（この手順では100点・S）で、ステージ2を選べることを確認する。終了前の続きとして誤って案内されないことも確かめる。
6. 再挑戦して最後まで演出を見た場合も、同じクリア記録が残ることを確認する。

保存拒否や古い通知の注入は自動検査で扱う。Safariのプライベートブラウズを「必ず保存拒否する条件」として扱わない。iPhoneの終了後Undoの見え方は、別途PR4で改善する対象として残す。
