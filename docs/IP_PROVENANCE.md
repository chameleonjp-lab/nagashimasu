# 実装と依存関係の来歴

更新日: 2026-08-13

## M1実装

`src/domain`のM1水流モデルは、本リポジトリの`docs/PROJECT_PLAN.md`と`docs/adr/0001-deterministic-water-model.md`を仕様として新規に実装した。

計画書の調査欄に記載した他作品、無ライセンス実装、ROM、逆コンパイル成果物から、コード、データ、アセット、画面構成をコピーまたは移植していない。作品名は比較調査を記録する計画書内だけで扱い、配布用コードやアセットには使用しない。

## 実行時依存

M1のゲームルール層に実行時の外部依存はない。
