## M4完了に必要な残作業

1. P0画面構成を公開版へ反映する。
2. iPhone実機で、回転、操作シート、盤面の池・雨・水・漏水位置を確認する。
3. 同じビルドを使い、初見プレイヤー3名以上でプロトコルを再実施する。
4. 目的理解、最初の施工、雨と水流の視認、最初の漏水原因、誤確定、継続意欲、ステージ1初見クリアを記録する。
5. 可能な環境で実ブラウザ自動E2Eを導入し、WebGL盤面入力、座標操作、確定、再生、結果表示を検査する。
6. 基準を満たした後、Sol・Highの独立レビューを受ける。
7. ユーザー本人がM4完了を判断してからM5へ進む。
