## M4完了に必要な残作業

1. 同じビルドを使い、初見プレイヤー3名以上でプロトコルを実施する。
2. 目的理解、最初の施工、最初の漏水原因、誤確定、継続意欲、ステージ1初見クリアを記録する。
3. 不合格項目があれば、ステージ追加ではなくチュートリアル、情報表示、操作導線、手数・雨間隔を修正する。
4. 基準を満たした後、Sol・Highの独立レビューを受ける。
5. ユーザー本人がM4完了を判断してからM5へ進む。
