## M4完了に必要な残作業

1. 今回の不合格を対象に、ゲームの目的、最初の操作、雨・水流・結果の因果が画面だけで伝わる導線へ修正する。
2. 同じビルドを使い、初見プレイヤー3名以上でプロトコルを再実施する。
3. 目的理解、最初の施工、最初の漏水原因、誤確定、継続意欲、ステージ1初見クリアを記録する。
4. 可能な環境で実ブラウザ自動E2Eを導入し、Canvas入力、セル番号操作、確定、再生、結果表示を検査する。
5. 基準を満たした後、Sol・Highの独立レビューを受ける。
6. ユーザー本人がM4完了を判断してからM5へ進む。
