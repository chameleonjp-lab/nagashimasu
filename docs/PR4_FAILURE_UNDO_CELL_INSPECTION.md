# PR4：失敗後の1手戻しと選択セルの確認

2026-09-09。基点はPR3マージ後のmain `71ec070e7d14991f6cc9e6e05bd7f21ea34e51c3`。Draft PRの対象SHAはPR本文にも記録する。

## 目的

iPhoneの狭い画面でも、失敗した直後に「どこから考え直せるか」を見つけられるようにする。既存のUndoと、StageSessionが返す予測・危険理由をそのまま使い、ルール計算や保存形式は変更しない。

## 実装

- 終了後の操作シートでも既存の「1手戻す」を表示する。失敗時は直前の有効手を1回だけ戻せること、Undo使用済み時は無効であることを結果欄に明記する。
- 再生中は従来どおり操作をロックする。Undoの実行は既存の`StageController.undo()`と同じ経路を使い、復元後の水流再生・保存・revision管理を変えない。
- 仮置き中の操作シートに、選択セルの現在の地形・水量、この手を確定した後の予測値、次の雨量、危険理由を短く表示する。
- 選択セルの説明は`StageTurnPreview`と`StageProjection`の証拠だけを整形する純粋なPresentation関数とし、表示のための再計算や、詳細欄を開くだけの状態変更を行わない。
- 危険理由は色だけでなく、保護セル浸水、危険側の出口、次の雨などの文章で示す。無効な仮置きでは予測を捏造せず、置けない理由を表示する。

## 自動検査

- `npm run check`: 型検査、全単体テスト、ドメインbuild・smoke、画面build・smoke。
- `cell-inspection.test.ts`: 現在値・予測値・危険理由の整形、無効配置時の非推測、範囲外入力の不変性を検査する。
- `app-markup.test.ts`／`app-smoke.mjs`: 選択セル確認欄、失敗後Undo説明、終了時に既存Undoを残すCSS契約を検査する。
- 既存のStageSession Undoテストを変更せず、ドメインの水流・勝敗・スコア・Replay・保存形式を維持する。

## iPhone 17 Proでの確認手順

1. PR4の確認用URLをSafariで開き、ステージ1を開始する。
2. 候補を選び、盤面の緑の丸を押す。操作シートに「選択セルの確認」が現れ、現在の地形・水量、予測値、危険理由が読めることを確認する。
3. 「盤面の見方・座標」を開閉するだけでは候補・仮置き・向きが変わらないことを確認する。座標ボタンを押した場合だけ、明示的に仮置きが変わることを確認する。
4. 失敗する手を確定し、雨・4回の水流の再生が終わった後、結果欄と操作シートに既存の「1手戻す」が見えることを確認する。
5. 「1手戻す」を押すと再生後に失敗前の手番へ戻り、もう一度候補とセルを選べることを確認する。Undo使用後はボタンが無効になり、再生中も押せないことを確認する。
6. 縦画面、横画面、文字拡大、VoiceOverで結果欄・Undo・選択セル説明が重ならず読み上げられることを確認する。

この手順は表示と操作の確認用であり、初見プレイ3名以上のM4ゲート判定や独立レビューの代わりにはしない。
