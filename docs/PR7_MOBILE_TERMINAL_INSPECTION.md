# PR7：モバイル終端操作とセル確認の到達性

基点はPR6マージ後のmain `d3790d9829bb0b86d140535346396e664a7a4364`。Draft PRの対象SHAはPR本文にも記録する。

## 目的

スマートフォンの狭い操作シートで、失敗後に考え直す導線と、盤面を調べたときの危険理由が下へ押し出されないようにする。ゲームのルール、Undo回数、チェックポイント、保存形式、勝敗判定は変更しない。

## 実装

- 終端結果欄の先頭に、既存の `StageController.undo()` と同じ経路を呼ぶ「1手戻す」を追加した。モバイルでは結果欄の上部に固定し、長い結果・シェア・ランキング欄をスクロールしても到達できる。
- 既存の操作シート内Undoはデスクトップ用に残し、モバイル終端では結果欄のボタンへ表示を集約する。未使用、使用済み、再生中の無効条件は既存のUndoボタンと同じ値を使う。
- モバイルの盤面タップで施工不可セルを選んだ場合は、仮置きや操作ログを変更せず、選択セルの確認だけを操作シートへ表示する。施工可能セルのタップは従来どおり仮置きする。
- 選択セルの確認に、現在の地形・水量、保護対象の有無、排水口の容量、施工後の予測または施工対象外、次の雨、危険理由を表示する。値は `StageProjection` と `StageTurnPreview` の既存証拠だけを整形し、Presentation側で水流を再計算しない。

## 自動検査

- `cell-inspection` の現在値・予測値・排水口／保護対象・危険理由の整形を検査する。
- アプリの結果Undo、選択セル確認欄、モバイル終端CSS契約を画面マークアップ／smokeで検査する。
- `npm run check`（型検査、46ファイル／243テスト、Domain build・smoke、画面build・smoke）を合格させる。

## iPhone 17 Pro確認手順

1. 所有者限定の確認ページでステージを開始し、施工不可のセルをタップする。
2. 操作シートにセルの現在値、保護対象／排水口、次の雨、危険理由が折り返されても読めることを確認する。候補、手数、Undo、操作ログが変わらないことを確認する。
3. 失敗する手を進め、再生完了後に結果欄の上部へ「1手戻す」が見えることを確認する。
4. 「1手戻す」を押すと、既存の再生後に失敗前の `awaiting-turn` へ戻ること、使用後はボタンが無効になることを確認する。
