# PR8：VoiceOver向けセル確認と終端Undoフォーカス

基点はPR7マージ後のmain `cb09b354fb78f50f5c3a83a00c24a8ea0cfd1713`。Draft PRの対象SHAはPR本文にも記録する。

## 目的

PR7で追加したセル確認を、盤面を直接押せないキーボード／VoiceOver操作でも利用できるようにする。終端結果では、失敗から考え直すための既存Undoへ最初に到達できるようにする。ゲームのルール、施工位置、Undo回数、チェックポイント、勝敗、水流、保存形式は変更しない。

## 実装

- 既存の「施工可能な座標」ピッカーは施工入力専用として残す。
- 新しい「セルを確認（施工位置を変えない）」ピッカーは64セルを表示し、押したセルを`inspectedCellIndex`へ記録するだけにする。
- セル確認ピッカーからの選択は`StageController`、仮置き、手数、操作ログ、保存値を変更せず、既存の`buildCellInspection`で現在値と危険理由だけを更新する。
- モバイル終端シートのフォーカス候補へ結果Undoを追加し、既存のUndo無効条件と同じく、対象手がない／使用済みの場合は再挑戦へフォーカスする。

## 自動検査

- セル確認ピッカーの64セル、選択中表示、手番外・不正インデックスの無効化を純粋なPresentation検査で確認する。
- 終端Undoが利用可能な場合のフォーカス選択と、利用できない場合の再挑戦フォールバックを検査する。
- アプリのマークアップ／smokeでセル確認ピッカーと説明文、タッチターゲット用CSSの配布を確認する。
- `npm run check`（型検査、47ファイル／248テスト、Domain build・smoke、画面build・smoke）を合格させる。

## iPhone 17 Pro／VoiceOver確認手順

1. 所有者限定の確認ページでステージ1を開始し、操作シートの「セルを確認（施工位置を変えない）」を開く。
2. VoiceOverの読み上げでA1、B2、保護対象または排水口を選び、選択セルの現在値、設備、次の雨、危険理由が読めることを確認する。
3. セル確認後に候補、仮置き位置、手数、操作ログ、保存状態が変わらないことを確認する。
4. 施工可能セルは既存の座標ピッカーから仮置きし、同じセル確認ピッカーを使って別セルを調べても仮置きが変わらないことを確認する。
5. 失敗する手を進め、終端シートを開いたとき、Undoが利用可能なら最初に「1手戻す」へ、使用済み／対象手なしなら「もう一度」へフォーカスされることを確認する。
6. 縦画面、横画面、文字拡大、VoiceOverの読み上げ順、44 CSS px以上のセルボタン、ページ横スクロールなしを確認する。
