# ADR 0008: 水流再生速度

## 状態

Accepted／M4実装中

## 背景

水流の再生は、施工結果を確認するために必要な時間だが、同じステージを繰り返すと長く感じることがある。一方で、速度だけを上げて重要な漏水や排水超過を省くと、失敗の原因を学べなくなる。

## 決定

- ステージ2をクリアした後、タイトル画面で「標準」または「高速」を選べる。
- ステージ2未クリア時は標準で再生し、高速選択を無効にする。
- 高速はPresentationのtrace区間の表示時間だけを短くする。
- 施工、雨、水流各step、評価の全イベントは高速でも省略しない。
- Domainの水流計算、StageSessionの評価、タイマー、操作ログ、Replay、Undoは速度設定から影響を受けない。
- 選択値は版付きlocalStorageへ保存し、既存の進捗保存v1は標準速度としてv2へ移行する。

## 禁止事項

- 高速設定でtraceイベントを間引かない。
- 水流計算や評価の回数を再生速度に合わせて変更しない。
- 再生速度をスコア、クリア判定、タイマー結果へ反映しない。
- 軽減動作設定を無視して、速度変更だけで強い点滅を追加しない。

## 検証

- 標準と高速で同じtraceイベント数になる単体検査
- 高速の各区間時間が標準より短く、0未満にならない単体検査
- 進捗保存v1からv2への移行と既存クリア記録保持
- ステージ2未クリア時の高速選択無効化を画面build／smokeで確認
- 既存の型検査、全単体テスト、ドメイン／画面build・smoke
