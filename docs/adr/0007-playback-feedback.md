# ADR 0007: 確定後の基本演出

## 状態

Accepted／M4実装中

## 背景

現在の画面は、施工・雨・水流・評価の順序を再生できる。しかし盤面上の強調が静的なため、何が進行中かを短時間で読み取りにくい。M4では、水が動く結果を装飾ではなく、確定操作の結果として追える表示が必要になる。

## 決定

- `StageSession`が返すtraceを唯一の演出入力とし、Presentation側で施工セル、雨セル、水流矢印を強調する。
- trace区間の進行値を0から1へ範囲内に収め、中央で最大になる脈動へ変換する。
- 演出はCanvasの色、不透明度、線幅、雨粒の大きさだけを変える。地形、水量、流向は再計算しない。
- 演出の進行値は保存、操作記録、StageSession状態へ入れない。
- 演出が終了しても、タイマー再開・結果保存・入力解除の順序は既存のApplication契約を維持する。

## 禁止事項

- Presentationから水流計算や評価を呼び出さない。
- 演出のフレーム時刻をDomainへ渡さない。
- 演出の見た目を、成功・失敗の判定条件に使わない。

## 検証

- 進行値の未定義、非数、範囲外を安全に丸める単体検査
- pulseが区間中央で最大となる単体検査
- 既存の型検査、全単体テスト、ドメイン／画面build・smoke
