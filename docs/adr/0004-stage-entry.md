# ADR 0004: タイトル画面とステージ入口

## 状態

Accepted／M4実装中

## 背景

M3までの画面は、起動するとステージ1がすぐ始まる状態だった。M4では、プレイヤーが目的と操作を理解してから遊び始め、ステージ1～3を選べる導線が必要になる。

## 決定

- 起動時はタイトル画面を表示し、盤面と施工ボタンはまだ操作できない。
- タイトル画面に、候補選択、仮置き・予測、施工確定の3段階を短く説明する。
- ビルトインのステージ1～3を選択できる。選択画面にはステージ名と主要目的を表示する。
- 開始時に選択された定義から新しい`StageController`を作る。既存のセッションを使い回さない。
- ステージ選択は画面側の状態であり、雨、地形、水流、評価の計算は`StageSession`へ委譲する。
- 結果画面からステージ選択へ戻れる。保存や解放条件は、時間制限・一時停止・保存機能と同じ後続作業で決める。

## テスト方針

- ステージ1～3が選択肢として表示される。
- 各ステージを選んで開始すると、対応するステージ名、目的、候補列、雨予報が表示される。
- 開始直後のセッションは新規状態で、前のステージの手数・候補・Undoを引き継がない。
- 既存の`npm run check`、画面ビルド、静的smokeが成功する。

## 制限

この導線では、時間の計測、ページ非表示時の停止、進行状況の保存、ステージ解放条件は扱わない。これらを追加するときは、画面の状態とDomainの時間・保存契約を分けて設計する。
