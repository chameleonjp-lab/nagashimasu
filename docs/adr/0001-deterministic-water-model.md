# ADR 0001: M1決定論的水流モデル

- 状態: 採用
- 決定日: 2026-08-13
- ルール版: `nagashimasu-water-v1`
- 再生記録版: `nagashimasu-replay-v1`

## 目的

同じ盤面と同じ操作から必ず同じ結果を得られ、水が途中で増減した場合に自動検査で停止できる、M1の水流規則を固定する。

この文書で決める数値は最終的な難易度調整値ではない。ただし、数値を変えると既存の操作記録と結果が変わるため、変更時はルール版を更新する。

## 盤面と数値

- 盤面は8×8、セル番号は左上を0とする行優先の0～63とする。
- 方向の正規順は北、東、南、西とする。
- 地形高さは0～6の整数で`Int8Array`へ保持する。
- 水量は0～65,535の整数で`Uint16Array`へ保持する。
- TypedArrayへ代入する前に範囲を検査し、桁あふれを丸め込まない。
- ゲーム判定はDOM、Canvas、端末時刻、描画フレーム、`Math.random()`へ依存しない。

## 水面と移動量

初期値は次とする。

- 高さ1段の水面換算値: 8
- 1セルが1固定ステップで出せる水量の上限: 8

水面は次で求める。

`水面 = 地形高さ × 8 + 水量`

1固定ステップでは、全セルが更新前の同じ盤面を読む。

1. 上下左右から、現在セルより水面が低い移動先を探す。
2. そのうち最も低い移動先だけを使う。
3. 出す水量を`min(現在水量, 8, floor(水面差 / 2))`で求める。
4. 移動先が複数なら均等に分ける。
5. 整数除算の余りは`(移動元セル番号 + 固定ステップ番号) % 移動先数`から、正規方向順へ循環して配る。
6. 全移動を`Int32Array`の差分へ記録し、計算後に一括反映する。

このため、セルを調べる順番を逆順や固定シャッフルへ変えても結果は変わらない。水面差が1だけの場合は、整数水量の均衡として移動しない。

## 盤外と排水口

- 盤面端は自動では開かない。ステージデータが安全辺または危険辺として指定した方向だけを出口にする。
- 盤外出口の仮想水面は`-8`とする。出口へ流れた水が次の固定ステップで盤面へ戻ることはない。
- 指定された盤外出口は常時開いた接続であり、出口セルの地形を上げても閉じない。地形工事は水を出口セルへ到達しにくくできるが、門の開閉はMVP後の別設備として扱う。
- 角で同じ最低水面の出口が複数ある場合も、通常の同率分配を使う。
- 安全辺へ出た水は安全排水、危険辺へ出た水は危険流出へ加える。
- セル型の排水口は、同期したセル間移動と盤外移動を反映する直前の次状態に対して処理する。
- 排水口は1固定ステップの能力まで安全排水し、能力超過分を同じセルへ残す。
- 排水能力は1手ではなく1固定ステップあたりの値とする。M2のステージデータは1手で進める固定ステップ数を明示し、水流の表示速度設定だけを変えても計算回数と排水量は変えない。

## 浸水と水量収支

保護対象の浸水は、水を消す処理ではない。固定ステップ後に許容量を超えた盤面水を被害の読み取り値として返し、その水は盤面に残す。

1手の途中で浸水し、最後の固定ステップまでに水が抜けた場合も被害は発生したものとして扱う。水流命令は全固定ステップのセル別浸水量を順番どおり返し、M2以降は初回発生ステップと最大浸水量を評価へ使えるようにする。

各降雨と各固定ステップで、次を完全一致させる。

`初期水量 + 追加雨量 = 盤面水量 + 累計安全排水 + 累計危険流出`

浸水量を右辺へ重ねて足すと同じ水を二重計上するため、水量収支には含めない。

## 施工、予測、再生

- 地形を上げ下げしても水量は変更しない。
- 無効な施工は、どのセルも変更する前に拒否する。
- 1固定ステップ予測は盤面を複製し、本番と同じ水流関数を実行する。予測専用の近似式は作らない。
- 各固定ステップは、セル間移動、盤外への安全排水・危険流出、排水口の処理、セル別浸水量を正規順で返す。表示、危険理由、失敗時の短い再生はこの記録を使い、見た目から流れを推測し直さない。
- 操作記録は雨、地形変更、水流ステップ数を順番どおり保持する。
- 各記録へ実行前後の状態ハッシュを保存し、異なる初期状態や改変された記録を再生時に拒否する。
- 状態ハッシュは偶発的な不一致や破損を見つける64ビット検査値であり、第三者による意図的な改ざんを証明する署名ではない。MVPは完全ローカルのため、ランキングの不正防止には使用しない。
- 1命令は複製盤面で最後まで検証し、全固定ステップが成功した場合だけ盤面と操作記録を同時に確定する。途中失敗した命令の変化は一切残さない。
- 1命令は最大64固定ステップ、1再生記録は最大10,000命令かつ累計100,000固定ステップとし、壊れた保存値による長時間停止を防ぐ。
- シード付き乱数はxorshift32を使い、seed 0は固定の非0シードへ写す。

## M1の停止条件

次のいずれかを検出した場合は値を補正して続行せず、検証エラーにする。

- 水量が負になる。
- セル水量が65,535を超える。
- 地形高さが0～6を外れる。
- 水量収支が一致しない。
- 操作記録の版、初期状態、前後ハッシュが一致しない。
- セル走査順によって結果が変わる。
