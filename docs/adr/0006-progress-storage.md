# ADR 0006: 設定とクリア記録の保存

## 状態

Accepted／M4実装中

## 背景

タイトル画面で選んだ思考時間や、クリアしたステージの最高点は、ページを閉じても残っている方が遊びやすい。一方、盤面途中の状態を不完全な形式で保存すると、StageSession、Undo、StageReplayの再現性を壊すおそれがある。

## 決定

- 保存先はブラウザの`localStorage`だけとする。ネットワーク、アカウント、外部サービスへ送らない。
- 保存キーは`nagashimasu.progress.v1`、ルートの`version`は`nagashimasu-progress-v1`とする。
- v1で保存するのは、思考時間設定、チュートリアル既読、最後に選んだステージ、クリア済みステージごとの最高点と最高評価だけとする。
- クリア記録は合計点を優先し、合計点が同じ場合は`S > A > B > C`の順で良い方を残す。タイマー設定は点数へ影響しない。
- 途中の盤面、候補、雨位置、Undo、再生位置、一時停止中の残り時間はv1へ保存しない。これらは`StageSave`の別バージョンと、保存時点の`StageReplay`再実行検証を設計してから追加する。
- `JSON.parse`後の値は厳格なcodecで検証する。未知のキー、未対応の思考時間、重複ステージ、範囲外の点数、壊れた配列を拒否する。
- 保存値が壊れている場合はそのキーを削除し、初期値でゲームを続ける。保存領域の読み書きが例外を出す場合も、ゲームを停止せずページ内の初期値だけで続ける。
- 保存値は決定論的な順序へ正規化し、読み込んだ値をそのまま後から変更できないように複製して凍結する。

## 禁止事項

- 保存値を`StageSession`の内部状態として直接復元しない。
- 保存値に壁時計、`Date.now()`、`performance.now()`、描画フレーム時刻を入れない。
- 壊れた保存値を黙って一部だけ採用しない。
- クリアしていないステージの最高点を作らない。

## 検証

- 標準／長め／無制限、最後のステージ、チュートリアル既読のJSON往復
- 合計点と評価の単調な最高記録
- 未知キー、重複ステージ、範囲外点数、無効な配列、アクセサ値の拒否
- 壊れたJSON、読み込み例外、書き込み例外から初期値で復帰
- 画面起動時の設定反映、ステージクリア後の記録、次回起動時の表示

## 未実装範囲

途中盤面の保存、リロード後の手番復帰、保存された操作列とsnapshotの照合は、StageSaveの設計後に実装する。
