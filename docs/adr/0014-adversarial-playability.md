# ADR 0014: 敵対的検証で見つかった画面操作と再生の境界

## 状態

Accepted／M4手動検証待ち

## 背景

公開版の敵対的検証で、Canvas上の小さいセル、重なった低地セル、色だけの意味表示、水流再生の視認性が初見プレイを妨げる可能性を確認した。単体の水流計算が正しくても、画面で合法位置を選べず、予報と危険の意味を読めず、水がどこへ動いたか見えなければゲームとして成立しない。

## 決定

- 合法な施工アンカーはCanvas上のマーカーに加え、セル番号のDOMボタンでも選択できるようにする。
- Canvas上の施工マーカーの当たり判定は直径44 CSS pxを下限とし、狭い画面でも指で狙えるようにする。
- セル番号ボタンは合法アンカーだけを有効にし、候補選択・回転・手番・再生・一時停止・終端に応じてdisabled状態を更新する。
- 盤面には、施工可能位置、予報、移動中の水、安全排水、危険流出、危険度を文章つきで示す凡例を常時表示する。
- 水流traceの`WaterTransfer`を再計算せず、記録された移動元、移動先、方向、移動量を再生進捗に沿って水色の点と数字で表示する。
- これらの表示はゲーム状態、ルール計算、操作列、保存データを変更しない。

## テスト方針

- 狭い盤面でも施工マーカーの44 CSS px当たり判定を検査する。
- 記録されたセル内移動と排水移動の補間点が、進捗0では移動元、進捗1では移動先になることを検査する。
- app smokeでセル番号選択、凡例、水移動表示、44 CSS pxスタイルの組み込みを検査する。
- Canvasを実ブラウザで操作するE2E、iPhone実機の初見プレイ、独立レビューは別ゲートとして未完了のまま扱う。

## 結果

Canvasの重なりだけに依存せず、キーボード・読み上げ利用者や狭い画面でも合法セルを番号で選べる。盤面の色の意味と、水流traceの移動量を同じ画面で確認できる。人手によるゲーム性判定はこの変更だけでは完了しない。
